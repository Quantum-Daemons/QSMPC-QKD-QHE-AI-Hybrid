#   works there. RHEL 9 / AlmaLinux 9 tops out at GLIBCXX_3.4.29 and the import fails.

#   SCOPE OF THAT FIX — it buys `import openfhe`, and nothing beyond it. Round 34 opened by
#   re-running the rebuild for a SIGSEGV it could not have fixed: the script had already been run

#   qsh/fhe/backends.py, which documents why each matters. Before reaching for this script, check
#   that `import openfhe` is the thing actually failing: a libstdc++ story that is true history is
#   not automatically the diagnosis for the next symptom.
#   Measurements: docs/verification-log.md, "Round 34".
