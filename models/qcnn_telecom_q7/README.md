# Variational QCNN - telecom, 7 wires

> **Round 46 re-measured this artifact.** The circuit was replaced with a real QCNN (shared two-qubit conv filter, pooling by conditioned rotation, register reduction); the previous figures came from a hardware-efficient ansatz that was labelled a QCNN and was not one. Current headline `macro_f1` = **0.510417**.

NOT PUBLISHED TO HUGGING FACE, AND NOT IN THE MODEL REGISTRY. This is a browser-side demonstration
circuit for the `telecom_ids` page of
[QSMPC-QKD-QHE-AI-Hybrid](https://github.com/thedaemon-wizard/QSMPC-QKD-QHE-AI-Hybrid). It carries no
`hf_repo` and no pinned revision.

## Why a second width exists

The browser's **QCNN qubits** control could not reach the trained circuit. `clientCompute.ts` read
the requested width and then loaded a fixed 8-wire file, so on every page shipping trained weights
the control moved the benchmark row and the untrained fallback and nothing else - an inert control,
the defect class the project's verification checklist opens with.

Making it real needed a second width to exist. Telecom is the case worth measuring: it encodes **7
features on 8 wires**, so the eighth is padded with `RY(0)` and carries no data. This model is the
same circuit trained at the width the data actually asks for.

## What it is

**6** conv rounds of a SHARED two-qubit filter (RY,RZ - CNOT - RY,RZ) with pooling by a rotation on the survivor conditioned on its partner, on **7 qubits**, reducing the register 7 -> 3; then a fully-connected block on the survivors (50 shared parameters), all 7 features encoded as
`RY(tanh(z) * pi)` on wires 0-6 with no padding wire. Readout, class map and scaling convention are
identical to the 8-wire card next door (`readout_qubits: 3`, `bit_order: "lsb_first"`,
`class_index: "c = i & 7"`, 8-element `scale`/`bias`) - only the width differs, which is the whole
point of the pair.

`src/qsh/qhe/qcnn_trained.py` reads `float(weights["scale"])` and therefore cannot consume this
artifact either, for the same reason as the 8-wire model: the Python reimplementation supports the
two binary use cases only.

## Measured

Same corpus, split, seed, layers and epoch budget as the 8-wire model. Only the width differs.

| | 8 wires (default) | **7 wires (this model)** |
|---|---|---|
| macro F1 | 0.510417 | **0.731204** |
| accuracy | 0.510417 | **0.735417** |
| classes predicted | 8 of 8 | **8 of 8** |
| classical LR macro F1 | 0.976447 | 0.976447 |

Floors, without which a macro F1 has no scale: uniform-random 0.1250, constant-predictor 0.0278,
majority-class accuracy 0.1521. **This model beats its floors and loses to the 8-wire model and to
classical logistic regression.** The LR figure is identical across the two runs because it never sees
the circuit, which is a useful control: an unchanged baseline is evidence the data path did not move.

Two of the eight classes are BETTER at 7 wires - `trojan_horse` +0.15, `combined` +0.01 - and the
per-class table is in [`references/qcnn-width-ablation.md`](../../references/qcnn-width-ablation.md)
because a single macro number would hide that. With one seed those two deltas are directional rather
than settled.

**No five-seed spread is published for this circuit**, for the same reason as the 8-wire model it is
compared against: one run is 6 layers x 400 epochs. Every figure on this card is therefore a draw and
not a median. The medical card records what that distinction cost where it WAS measured - its seed 0
turned out to be the worst of five, understating that circuit by a wide margin - so the absence of a
sweep here is a limit on what these numbers support, not a sign that they are stable.

**Seed position:** unmeasured - no five-seed spread was run for this circuit, so both the macro
number and the two per-class deltas above are one draw and not a median.

## Reproducing

    python scripts/train/qcnn_variational.py --usecase telecom --layers 6 --epochs 400 --seed 0 --threads 1 --qubits 7

That command is recorded inside `weights.json` and reproduces `theta` exactly. `--qubits` is in the
string because it changes the weights: the first run of this model recorded a command without it,
which reproduced the EIGHT-wire model instead - a reproduction line that does not reproduce is worse
than none, because it gets checked once and trusted afterwards.

## Scope

Simulated state-vector circuit trained by backpropagation, not quantum hardware and not a claim of
quantum advantage. The corpus is synthetic QKD-attack telemetry generated by `qsh.qml_ids.attacks`
with class structure per Al-Kuwari et al. (arXiv:2509.14282); no commercial-OK real attack corpus
exists, which is why no number here is a performance claim about a real link.
