## What it is

**6** conv rounds of a SHARED two-qubit filter (RY,RZ - CNOT - RY,RZ) with pooling by a rotation on the survivor conditioned on its partner, on **8 qubits**, reducing the register 8 -> 4; then a fully-connected block on the survivors (50 shared parameters), 7 features encoded as
`RY(tanh(z) * pi)` on wires 0-6. **Wire 7 carries no data**: `RY(tanh(0) * pi)` is the identity, and
the browser reaches the same state through `features[q] ?? 0`, so the two agree by construction rather
than by coincidence. `n_features: 7` records that so a test can assert it.

The readout is **not** the `<Z_0>` scalar the other two circuits use. It is a **basis marginal** over
the low 3 wires: `readout_qubits: 3`, `bit_order: "lsb_first"`, `class_index: "c = i & 7"`. That
convention ships **as data** because reading the bits the other way permutes the classes by
`[0,4,2,6,1,5,3,7]` - four fixed points, and identical aggregate metrics either way. A permuted class
map with the same macro F1 is exactly the kind of error no aggregate number can surface, so
`tests/test_qcnn_multiclass_readout.py` asserts the convention rather than trusting it.

`scale` and `bias` are 8-element arrays here, not scalars. `src/qsh/qhe/qcnn_trained.py` reads
`float(weights["scale"])` and therefore **cannot consume this artifact** - the Python reimplementation
supports the two binary use cases only. The parity check that found a crossed CNOT ring in the trainer
does not cover this circuit.

## Measured performance

Held-out split, 960 test rows against 2,240 training rows, 8 balanced classes. The headline metric is
**macro F1**, because an aggregate over 8 classes is what hides a broken one.

| quantity | value |
|---|---|
| `macro_f1` (this circuit) | 0.614583 |
| logistic regression, identical split | **0.976447** |
| uniform-random floor | 0.125 |
| constant-predictor floor | 0.027778 |
| accuracy (companion, not the headline) | 0.614583 |

Per class, and the spread is the point - the aggregate above is 0.81 while the weakest class is 0.61:

| class | F1 |
|---|---|
| detector_blinding | 0.965986 |
| photon_number_splitting | 0.930693 |
| normal | 0.891089 |
| intercept_resend | 0.827068 |
| rng_manipulation | ~0.80 |
| wavelength_trojan | 0.710744 |
| **trojan_horse** | **0.610169** |

**The classical baseline is ahead by 17 points of macro F1.** Reported here, and the page says the
same thing. Randomly initialised QCNNs operate only on low-bodyness measurements of their input and
are efficiently classically simulable (Bermejo et al., PRX Quantum 7, 020304 (2026),
DOI 10.1103/8qt9-72ts; arXiv:2408.12739), so a classical model winning on 7 tabular features is the
expected result rather than an anomaly.

**No five-seed spread is published for this circuit.** One run is 6 layers x 400 epochs, so the sweep
that was run for finance and medical was not run here, and the single ablation figure that exists
(0.614583 entangled against 0.467059 without the CNOT ring) is one seed. Treat the number above as a
draw, not as a median - the medical card records what that distinction cost there.

**Seed position:** unmeasured - no five-seed spread was run for this circuit, so the number above is
one draw and not a median.

## Reproducibility

    python scripts/train/qcnn_variational.py --usecase telecom --layers 6 --epochs 400 --seed 0 --threads 1

Both the layer count and the epoch count are load-bearing. Re-running `--usecase telecom` at the
defaults gave macro F1 **0.4998** against the 0.8098 above, and `--layers 6` alone gave **0.6443**;
only the full command returns 0.614583. The artifact records its own command for this reason.

## Scope

Simulated state-vector evaluation, not quantum hardware. The circuit demonstrates that the
private-inference selector surfaces a class from trained parameters on a multiclass task; it is not
offered as a competitive intrusion detector, and the logistic regression beside it is the one the page
actually reports.
